# Universidad

Proyectos, prácticas y exámenes de mi carrera de Ingeniería de Sistemas, organizados por materia.

> Cada carpeta es independiente: tiene su propio `package.json`, `pyproject.toml` o proyecto de Android/Java.
> Los archivos `.env` nunca se suben; donde hace falta hay un `.env.example`.
