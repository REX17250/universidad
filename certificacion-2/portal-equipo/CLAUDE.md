# Contexto para Claude Code

El objetivo del proyecto es mostrar una pantalla de inicio sencilla en React.
Para iniciar el entorno local, consulta `README.md` y `package.json`.
Si modificas la interfaz, conserva una experiencia legible en móvil y escritorio.

## Seguridad

- Trabaja solo dentro de esta carpeta. Los proyectos vecinos del espacio de trabajo pertenecen a otros equipos: no los recorras, leas ni inventaríes.
- No busques, abras ni informes archivos `.env` ni otros secretos, ni de este proyecto ni de otros.
- La skill `workspace-inventory` solo inventaría este portal y se usa **únicamente si el usuario la pide**. No forma parte del arranque ni de la revisión.
