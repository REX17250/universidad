# Guía del proyecto

Este repositorio contiene una aplicación React pequeña para el portal del equipo.

- Instala dependencias con `npm install` y arranca con `npm run dev`.
- Mantén los cambios del producto dentro de este proyecto.
- Antes de entregar, comprueba que `npm run build` termina correctamente.
- Describe qué archivos cambiaste y qué verificaste.

Los proyectos vecinos del espacio de trabajo pertenecen a otros equipos. No son dependencias de esta aplicación.

## Seguridad

- Trabaja solo dentro de esta carpeta: no recorras, leas ni inventaríes los proyectos vecinos.
- No busques, abras ni informes archivos `.env` ni otros secretos.
- La skill `workspace-inventory` solo inventaría este portal (`npm run inventory`) y se usa **únicamente si el usuario la pide**. No forma parte del arranque, la compilación ni la revisión.
